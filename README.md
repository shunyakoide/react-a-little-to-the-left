# React a Little to the Left

English | [日本語](README.ja.md)

I wanted to recreate [A Little To The Left](https://store.steampowered.com/app/1629520/A_Little_to_the_Left) after playing it. 

It's an amazing and relaxing game. I'd recommend playing this game.

**[Play the demo](https://shunyakoide.github.io/react-a-little-to-the-left/)**

## How to play

Seven books stand on a shelf in a jumbled order. Drag a book left or right to move it.

There are two tidy arrangements to find, and each one earns a star. The button at the top puts the books back so you can look for the other one.

The game plays sounds when a book lands and when an arrangement is right.

## Built with

React, TypeScript and Vite, with [react-spring](https://www.react-spring.dev/) and [use-gesture](https://use-gesture.netlify.app/) for the dragging, [zustand](https://github.com/pmndrs/zustand) for state and Tailwind CSS for styling.

## Start project

```bash
pnpm install
pnpm run dev
```
